FFmpeg —— 第三方组件许可说明
================================

本目录下的 ffmpeg.exe 与 ffprobe.exe 是随本软件一起分发的第三方程序，
用于视频去重处理、分片拼接与兼容格式转码。

构建信息
--------
版本       : FFmpeg 9.0.2-hongguo-nvenc12.2
来源       : 本仓库 scripts/build-ffmpeg-source-win.sh，从固定源码编译
发布       : https://github.com/XASDSdsa/hongguo-drama-mac/releases/tag/ffmpeg-9.0.2-nvenc12.2
下载       : 同一发行页的 ffmpeg-9.0.2-nvenc12.2-win-x64.zip
ZIP SHA256 : 见 WINDOWS-BUILD.json 及发行页的 .sha256 文件
官方源码   : https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
NVENC API  : 固定 nv-codec-headers n12.2.72.0，兼容驱动提供的 API 12.2
构建依赖   : x264、libvpl 2.17.0、AMF 1.5.2 头文件、zlib 1.3.2
libvpl 补丁: 仅修正旧 MSVC shim 条件，准确补丁随对应源码包附带
构建配置   : 见随程序附带的 BUILD-REPORT.txt
版权       : Copyright (c) 2000-2026 the FFmpeg developers

许可证
------
该构建的配置中包含 `--enable-gpl --enable-version3`，因此其许可证为
**GNU General Public License version 3 or later（GPLv3-or-later）**。
未启用 nonfree。PE 导入仅包含 Windows 系统库，不需要用户安装编译工具；
硬件编码运行时使用已安装的相应显卡驱动。

随本目录附带的许可证全文：

获取对应源码
------------
上述固定发行页提供 ffmpeg-9.0.2-nvenc12.2-win-x64-source.tar.xz，
包含 FFmpeg、所有静态依赖及硬件编码头文件的准确源码归档、
校验值、实际构建配置和构建脚本。构建期使用的 MSYS2 工具版本
列于 BUILD-REPORT.txt。只下载本应用仓库的源码不能替代该对应源码包。

说明
----
FFmpeg 是独立的第三方程序，与本软件之间通过命令行调用交互。
本软件仅调用其公开的命令行接口，未修改 FFmpeg 源码。
