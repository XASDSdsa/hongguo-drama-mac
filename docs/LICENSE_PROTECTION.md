# 1.2.55 应用代码与授权保护

Windows 经原有软件内更新下发应用小包，仍只更新 ASAR、更新配置和对应 EXE 资源段，不携带 Electron、Java、FFmpeg、模型或 Office 运行库。

## 发布代码

构建在临时快照中处理主进程、预加载和本地业务 JavaScript，使用固定版本的开源 javascript-obfuscator 做标识符/字符串混淆。维护源码不覆盖，第三方依赖不混淆。React 界面保留 Vite 压缩，不发布 source map。

每个文件记录源与产物 SHA256；验收重新生成受保护代码并对照实际 ASAR。混淆发生在 ASAR 完整性哈希及签名生成之前，保留原有 Electron fuses。构建工具仅为开发依赖，不随软件安装。

混淆提高阅读和修改成本，并非不可还原的代码加密。发布源码公开时，混淆也无法让已公开的算法变成秘密。仅由客户端执行的授权仍可被有能力的攻击者研究绕过。

## 授权运行状态

- 启动仍必须联网验签、核对产品、设备、状态及有效期；只保存系统安全存储加密的激活码，不保存可供下次离线启动的通行状态。
- 运行中每 5 分钟复核。关键任务前，最近成功结果超过 60 秒时复核；并发调用共享请求，失败后按 60 秒重试。用户可手动重新验证（5 秒节流）。
- 仅网络错误、HTTP 5xx 和 429 允许短时缓冲。缓冲从最近成功验证起最多 15 分钟，且不能超过已签名的凭证或授权到期时间。单调时钟也限制缓冲，避免简单回拨系统时间延长使用。
- 服务端明确停用、到期、设备不匹配、签名错误或无效响应均拒绝新任务。断网不能复活已被明确拒绝的授权。
- 主进程检查关键 IPC 的发起窗口和运行授权，覆盖下载/重试、合并/去重、字幕/分析、AI、草稿及报告生成等入口。取消、查看已有结果、日志和软件更新继续可用。
- 已在执行的任务不强杀、不删除文件；待调度下载保留在队列，恢复授权后继续。没有实现跨进程原生授权或服务端执行核心业务。
- 界面显示失效/网络状态并可重试；取消退出不会停止心跳，真正退出才清理会话。

Mac 本轮不发布新的安装包，已发 Mac 1.2.54 不会因此自动升级。Mac 构建入口也已接入快照保护，后续打包时使用。

## 验证

`node scripts/check-license-protection.cjs`：真实 Ed25519 签名、伪造/设备/产品/有效期拒绝、断网/停用/恢复/时钟/并发、关键操作及主进程 IPC。

`node scripts/check-online-startup.cjs`：实际在线启动模块的激活、取消、安全保存、已存码联网验证、运行期撤销和异常清理。

`node src/components/check-ui-state.cjs 'license status UI'`：事件与初始状态竞态、重试和恢复。

Windows 发布还要求真实上一版更新器安装小包、启动授权页、数据和运行库保留、源/保护产物对应，并从安装后的 ASAR 执行以上授权模块测试。小包继续使用 25 MiB 硬上限。
