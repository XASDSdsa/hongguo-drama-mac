# 台词与视觉分镜关联规则

2026-10-17 · 视觉分镜不变；台词策略 paraformer-ct-global-whisper-audio-pause-v4；字幕导出 voice-segments-v1

## 流程
媒体基准 → 视觉分镜；整集音频 → 人声/背景分离 → 台词识别、真实音频停顿检测与声学时间对齐；两路齐备后 → 关联台词与分镜 → 按原切点导出视频 → SRT/文件清单 → 剪映草稿。

## 边界规则
- 已确认的 TransNet V2 算法和原始 shots.json 保留不变，所有画面切点都按原帧和时间保留。
- 不为台词合并或移动视觉切点。连续说话可以自然跨多个画面镜头；同一画面镜头也可以有多个实际停顿分开的人声片段。
- 人声切点只采信音频中的实际停顿，并由语音活动检测确认。识别出的逗号、句号、问号等只保留在文字中，不是切开连续说话的依据。
- 词级时间戳用于把文字对应到音频，词时间之间的间隙本身不能证明发生停顿；不按字数或时长均分。找不到可靠的音频停顿时保留连续人声并标记待检查，不硬切。
- 模型的识别窗口是计算边界，不是成品边界。窗口两侧仍在连续说话时合为连续人声，不因到达窗口上限分割。
- 低文字概率保留有效时间并标记待检查；缺少或无效时间则保留原段并警告，不伪造切点。
- aligned.json 中每句关联 exact shot_ids；segments 仅记录交叠索引，不是拆成新的字幕或人声素材。遗漏、重复、伪造的镜头关联会拒绝交接。
- clips.json 必须一一对应原始视觉镜头，没有内部合并切点；视频不缺帧、不重帧、不改变原始切点。
- 字幕以已正确生成的人声片段为唯一时间依据：每个 voice segment 对应一条字幕，直接使用其开始和结束时间。即使同一识别台词跨多个有声片段，也不能用整句首尾铺满中间静音。
- 字幕文字依据 recognition.raw.json 的源 VAD 文字和 source_segment_ids 顺序配对，全文拼接必须守恒；不把整句重复到各片，不按字数或时长均分。来源缺失或归属不唯一时明确报错，不猜测。
- 草稿字幕直接以微秒创建 TextSegment，与对应配音 target_timerange 完全一致；SRT 单独按格式要求量化到毫秒。每条 cue 以 voice_segment_id 关联，缺失、重复、错配或时间被拉长必须拒绝。
- 背景声整集一条；特效声按视觉分镜。字幕是否跨镜头只取决于对应人声是否跨镜头，不改变画面或音频迁就字幕。
- 字幕轨保留、隐藏且缩放 1%；公司与声明水印规则不改。

## 旧项目
旧标点分段、词时间间隙分段或 VAD 计算窗口直接分段的台词及相应草稿必须更新。选择「继续完整流程」更新人声分段，再建立关联、导出和草稿；只点生成草稿不能修正旧的人声边界。旧结果保留供核对，但不冒充新算法结果。

仅 media/audio/shots/separation 可按本次明确审核的旧→新实现哈希对迁移缓存。迁移仍核对源视频内容与路径、参数、模型、工具、前置结果和全部输出哈希；未知代码或二进制变更不能套用迁移。transcript 不参与旧缓存迁移。

## 验证
- npm run check:dialogue：同句跨三个镜头、同镜头内不同句、47 秒链式合并回归、所有切点及帧完整保留、台词不重复丢字、映射遗漏/重复/伪造拒绝。
- 调度检查：旧台词与草稿失效、单步依赖、只迁移已确认的上游哈希、输入/模型/工具/输出变化拒绝复用。
- 剪映草稿校验：视频切点一致；每条字幕与对应人声时间一致；背景声一条；特效声按视觉镜头；全局 SRT 时间与文本一致。
- 音频回归必须覆盖：连续说话中的错误标点不切；只有词时间间隙但实际持续有声不切；有可靠停顿但识别无标点仍能切；短暂低能量不能被当作停顿；跨识别窗口的连续说话不硬切；文本不丢不重、人声与字幕同起止。
- 旧的逗号分段验收只记录旧版本行为，不能作为本算法通过的证据。真实音频验收与合成回归分开记录；未取得用户截图所对应的原始音频时，不能声称已复现或验证该片段。

## 精度范围
台词识别、标点、语音活动检测与声学对齐仍可能有错字、漏句和边界误差。音频停顿不等于语义完整的一句话，不能保证百分之百正确；本规则保证不把识别标点直接当成切点。SRT 毫秒格式不等于毫秒识别精度。视觉分镜和人声分别核验，不用合并镜头掩盖识别问题。
