# 用户确认的切镜算法 V1

算法唯一标识：transnetv2-temporal-min2s-v1。2026-10-14 用户观看“时间结构复核＋最短2秒”结果后，明确确认效果并要求记录。后续开发以本目录冻结版本为基准。

## 固定逻辑

1. TransNet V2 只用 single 分数、阈值0.5产生候选；每段连续高分只取第一个最大峰。all 分数不单独触发切割。
2. 160×90低清全帧用于复核，灰度缩小到64×36，3×3高斯模糊、亮度归一化与小幅平移匹配。多个时间窗口确认结构连续时排除闪光/特效；片头淡入并入首镜头。不确定点保留warn。
3. 完整公式及数值以 verify.py 和 recipe.json 为准。后续不能悄悄替换成提高阈值、最近帧判断或两路OR规则。
4. 在复核候选中用动态规划保留累计single分数最大的边界集合；首段、中段、尾段均不少于2秒。短片段只合并，不删帧、不补帧。整片不足2秒时整体保留并注明例外。
5. 按原始逐帧PTS和真实video_end定位，不能按平均帧率换算，不做整数秒落刀。

## 已确认样本

《我，万古第一第一季》第103集，已去重输入；2270帧，90.833334秒。原规则38段，确认版本22段，最短2.041666秒。21个保留边界、完整PTS、模型分数、源视频SHA256和复核记录均在 accepted-baseline.json。

22段是本集结果，不是其他视频必须达到的数量。2秒是输出片段长度规则，不代表真实镜头永远不会短于2秒。26.875秒warn候选最终被时长约束合并；阶段记录与最终边界需区分。

## 复现与修改约束

- verify.py、duration_policy.py 是当次实测的原样副本；manifest.json 保存SHA256。当前仅归档，不会改变正式软件行为。
- verify-baseline.py 核验指纹、完整覆盖、最短时长、22段输出；传入原视频160×90 RGB全帧.npy文件可同时复测结构判定。
- 正式接入时先确保本样本保留边界完全一致。优化参数应建立新版本对比，不能覆盖本版本或悄悄改默认。
- 用户确认的是本集视觉效果，不是跨所有片源100%准确率。
