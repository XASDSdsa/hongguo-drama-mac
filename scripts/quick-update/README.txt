changeFileName Windows x64 快速更新

适用于已安装 Windows 1.2.39 完整版或已更新至 1.2.40 / 1.2.41 的电脑。
先退出 changeFileName，完整解压 ZIP，然后双击 update.cmd。
如果没找到安装位置，将包含 changeFileName.exe 的安装文件夹拖到更新窗口，按回车。
完成后按原来的方式打开软件。报告转换组件及用户资料继续使用当前安装中的文件。
之前生成的报告需重新生成 Word，再导出 PNG，才会使用新金额和导出规则。
PNG 导出使用模板原字体。原字体无法用于转换或排版有变化时，会在软件中提示。
Windows 导出使用已安装的桌面版 WPS 文字排版，随后完成 PNG 的倾斜、纸面噪点和文字重叠处墨色处理。
